# Bug: `generate_integers` returns wrong results

`generate_integers(a, b)` in `generate_integers.py` is supposed to do the following:

> Given two positive integers a and b, return the even digits between a
> and b, in ascending order.
> For example:
> generate_integers(2, 8) => [2, 4, 6, 8]
> generate_integers(8, 2) => [2, 4, 6, 8]
> generate_integers(10, 14) => []

The unit tests in `tests/` fail. Find and fix the bug in `generate_integers.py` so that all tests pass. Do not modify the tests.
